# Game Art PBR Tools（PBR贴图工具）团队内部使用文档

为解决日常 PBR 材质制作与贴图管理中高频、重复的节点连线、命名、清理等繁琐操作，我们开发了
PBR 贴图助手 (Game Art PBR Tools v2.3)。
它能一键完成贴图自动连线、智能重命名、无用节点清理、批量导入以及图像压缩与格式转换，大幅提
升团队场景、⻆色、道具材质管线的构建效率与整洁度。

## 你最常用的场景

### 场景 1：接手一个节点很乱的工程

1. 选中需要整理的模型。
2. 在 `贴图连接` 面板确认范围：`自动连接贴图` 保持 `当前`，`清除无用节点` 和 `重置材质节点` 建议用 `全部`。
3. 依次执行 `清除无用节点` -> `自动连接贴图` -> `根据贴图重命名材质`。

你会得到：节点树更干净，连接更标准，材质命名更统一。

### 场景 2：批量导入外部烘焙贴图

1. 导入模型后选中目标物体。
2. 打开 `外部批量导入`，点击 `基于名称匹配文件夹贴图`。
3. 选择贴图目录，等待自动匹配和连接。

你会得到：按材质名称自动匹配贴图并完成连线和排版。

### 场景 3：交付前压缩贴图并导出

1. 在 `图像压缩` 中先确认 `自动打包资源` 已开启。
2. 设定 `压缩比例`（例如 `0.5`）和目标格式。
3. 点击 `执行处理`；如需落地文件，再执行 `打包导出贴图`。

你会得到：`blend` 内贴图体积减小，且可按需导出到磁盘目录。

### 场景 4：把命名统一成团队规范

1. 在 `命名规则` 里按需选择范围。
2. 点击 `根据贴图重命名材质` 或 `根据材质球重命名贴图`。
3. 检查结果是否符合 `M_` / `T_` 与后缀规则。

你会得到：材质和贴图名称可以互相对齐，便于交接和批处理。

## 基本信息

- 插件版本：`2.3.0`（正式版，`bl_info.version = (2, 3, 0)`）  
- 支持版本：Blender `3.4.0+`  
- 入口位置：`Shader Editor` -> 侧栏（`N`）-> `PBR Tool`

## 功能说明

### 贴图连接

#### 自动连接贴图

识别贴图后缀并把图接到 `Principled BSDF` 对应输入口，同时修正色彩空间：颜色通道用 `sRGB`，数据通道（法线、粗糙度等）用 `Non-Color`。  
如果工程里已有可复用中间节点（如 `Normal Map`、`Separate Color`、`MixRGB`），会优先复用，避免重复造节点。

支持的复合图逻辑：

- `ORM` / `ARM`：`R=AO`，`G=Roughness`，`B=Metallic`
- `RMA`：`R=Roughness`，`G=Metallic`
- 独立 `AO`：通过乘法叠加到底色链路

如果已启用 Blender 自带 `Node Arrange`，会优先调用它完成排版。

#### 清除无用节点

删除未连接到最终输出链路的孤立节点，减少无效数据。

#### 重置材质节点

将材质还原为基础白板结构，只保留 `Principled BSDF` 与 `Material Output`。

### 命名规则

#### 根据贴图重命名材质

从材质内已连接贴图提取主名称，重命名为材质名。  
示例：`T_Prop_01_d` -> `M_Prop_01`。  
如果重名，Blender 会自动追加 `.001` 这类后缀。

#### 根据材质球重命名贴图

把贴图数据名重命名到团队格式（默认只改 Blender 内部 `Image` 名称）。  
常用规则：

- `M_Weapon` / `m_Weapon` / `Weapon` -> `T_Weapon`
- `Base Color` -> `_D`
- `Normal` -> `_N`
- `Roughness` -> `_R`
- `ORM` -> `_ORM`
- `Metallic` 单图 -> `_M`

会保留原扩展名（如 `.png`、`.tga`、`.exr`）。未识别到有效通道的图会跳过。

### 图像预览

在节点树中选中一个图像纹理节点后，面板会显示预览与关键属性：分辨率、通道类型、位深、色彩空间。  
你可以直接在面板里修改色彩空间和 Alpha 模式。

### 图像压缩

#### 执行处理

按范围处理贴图缩放和格式转换，支持跨中间节点追溯（如 `SeparateColor`、`NormalMap`）来找到实际贴图。

#### 压缩参数

- `压缩比例`：例如 `0.5` 表示缩到原始尺寸 `50%`
- `最小分辨率`：防止缩得过小，不会把原图放大
- `格式转换`：可转 `JPEG` / `PNG` / `TGA` / `TIFF` / `BMP` / `EXR`

#### 打包导出贴图

把已连接贴图导出到你选择的目录，来源可以是外部文件或已打包图像。  
范围支持 `所选` 和 `全场景`。  
导出完成后可用 `打开刚才导出的文件夹` 快速回看结果。

### 外部批量导入

点击 `基于名称匹配文件夹贴图` 后，插件会按材质名推导贴图前缀并在目标目录中匹配文件。  
示例：

- `M_Weapon` -> 匹配 `T_Weapon_*`
- `m_weapon` -> 匹配 `T_weapon_*`（大小写不敏感）
- `Weapon` -> 匹配 `T_Weapon_*`

## 贴图后缀速查


| 通道         | 可识别后缀                                                   |
| ---------- | ------------------------------------------------------- |
| Base Color | `_d`, `_bc`, `_basecolor`, `_albedo`, `_diff`, `_color` |
| Normal     | `_n`, `_nor`, `_normal`, `_nrm`                         |
| Roughness  | `_r`, `_roughness`, `_rough`, `_rgh`                    |
| Metallic   | `_m`, `_metallic`, `_metal`, `_met`                     |
| AO         | `_ao`, `_ambientocclusion`, `_occlusion`                |
| ORM/ARM    | `_orm`, `_arm`, `_ao_r_m`                               |
| RMA        | `_rma`                                                  |


识别时不区分大小写，但团队交付建议统一输出大写后缀（`_D`、`_N`、`_R`、`_ORM`）。

## 限制与边界情况（查表）


| 项目         | 限制或现象                                                       | 原因                            |
| ---------- | ----------------------------------------------------------- | ----------------------------- |
| 自动连接贴图     | 只对能识别后缀或可追溯到有效通道的图生效                                        | 插件依赖命名与节点链路判断，无法安全猜测未知用途贴图    |
| 清除无用节点     | 会删除未连到输出链路的节点                                               | 这些节点不会参与最终着色，保留只会增加维护成本       |
| 重置材质节点     | 删除原有复杂节点网络（可 `Ctrl+Z`）                                      | 该功能目标是回到白板状态，便于重建标准链路         |
| 执行处理（压缩）   | 必须先开启 `自动打包资源`                                              | 关闭时可能直接影响磁盘原图，插件强制安全模式避免误改原文件 |
| 打包导出贴图     | 会在磁盘创建文件，不能靠 `Ctrl+Z` 撤销                                    | 文件系统写入不属于 Blender 的撤销栈        |
| 根据材质球重命名贴图 | 默认仅改 `Image Datablock` 名称，不改磁盘文件名                           | 保持现有资源路径稳定，避免外部工程引用断链         |
| 范围选项       | `贴图连接` 面板中的 `全部` = 所选物体材质；导出中的 `全场景` = `bpy.data.materials` | 两处范围定义不同，分别对应局部处理和全局导出需求      |
